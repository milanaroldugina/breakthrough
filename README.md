# 🤖 ПРОРЫВ / BREAKTHROUGH

Интерактивная игра реального времени с компьютерным зрением, где игрок соревнуется с автономным роботом. Робот использует алгоритм поиска кратчайшего пути по сетке для динамической навигации, а игрок может строить препятствия прямо на видеопотоке с камеры, чтобы помешать ему достичь цели.

## 🎮 Как это работает

- **Робот** (с маркером ArUco ID=3) автономно строит маршрут и пытается добраться до ворот (маркер ID=0).
- **Игрок** рисует стены левой кнопкой мыши, создавая лабиринт в реальном времени.
- **Стены** постепенно "тают" (исчезают благодаря морфологической эрозии), поэтому защиту нужно постоянно обновлять.
- **Запас чернил** ограничен – каждое препятствие стоит ресурсов, нужно строить с умом!
- **В доработке - 3 уровня сложности**: влияют на запас чернил и видимость маршрута робота.

## 🛠 Технологии

- **Python 3.13** – основной язык разработки
- **OpenCV** – компьютерное зрение и детекция ArUco-маркеров (DICT_4X4_50)
- **NumPy** – эффективная работа с матрицами, векторами и масками изображений
- **A* (A-star) Algorithm** – динамический поиск кратчайшего пути с учетом габаритов робота и меняющихся препятствий
- **Socket (TCP/IP)** – низкоуровневая связь с микроконтроллером робота по Wi-Fi
- **Arduino Nano/Uno** — микроконтроллер робота, управление моторами через ШИМ, чтение энкодеров, PID-регуляторы скорости
- **ESP32-C3** — Wi-Fi модуль, TCP/IP связь с Python (SoftwareSerial)
- **Motor driver + DC motors** — дифференциальный привод с энкодерами (358 тиков/оборот)
